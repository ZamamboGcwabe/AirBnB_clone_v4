This project focuses on learning how to manipulate the DOM, handle user interactions, and make AJAX requests using jQuery (version 3.x). You will dynamically update HTML elements—modifying content, styles, and structure—without reloading the page. The project also covers binding to user and DOM events, working with GET and POST requests, and interacting with your own REST API in a responsive and user-friendly way. All JavaScript must be placed in the **scripts** folder, written using `let` and `const`, and formatted according to **semistandard** rules.

This project works with a Flask-based REST API that uses Flasgger and Flask-CORS, which must be installed locally along with required dependencies. Troubleshooting common issues such as jsonschema errors or missing modules like `pathlib2` may be necessary. jQuery must be imported into your HTML, and all changes to the page should rely on DOM manipulation rather than page reloads. This project reinforces core web development skills including event handling, AJAX, API usage, and dynamic interface updates.
